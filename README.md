# SUKOON housewarming invitation

A colourful, responsive invitation for Mr. & Mrs. Ahammed Razik Vengatt’s housewarming on 12 December 2026. The design combines an emerald and rose palette, botanical artwork, an arched house photograph, and Arabic blessings.

Built with HTML, CSS, JavaScript, and inline SVG, with no framework or build step. Features include optional background music, an India-time countdown, Google Maps directions and QR code, calendar link, address copying, and a lantern guest selector that prepares a WhatsApp message for the visitor to send.

To run locally, serve this directory with any static HTTP server, for example `python3 -m http.server 8080`, and visit http://localhost:8080. Netlify publishes the project root directly.
